# The Elite Stay PG & Hostel Website

## Folder
- index.html → Home page
- room.html → Room detail page
- assets/css/style.css → All design/responsive CSS
- assets/js/script.js → Sliders, filters, WhatsApp form
- assets/images/ → Replace images here
- assets/videos/ → Put room-tour.mp4 here later

## Very easy changes
Open `assets/js/script.js`:
- Change `whatsappNumber`
- Change `instagramUrl`
- Change `heroSlideSeconds`
- Change `roomPhotoSeconds`

Open `index.html`:
- Change room names/prices
- Change facilities
- Change address/location text
- Change image file names

## Image replacement
Keep your own images in `assets/images/` and simply replace:
hero-1.jpg
hero-2.jpg
hero-3.jpg
room-1.jpg ... room-6.jpg
about-1.jpg
about-2.jpg

The website uses normal local image paths, so no complicated image system is required.
